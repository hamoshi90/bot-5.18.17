تشغيل على ويندوز (الأسهل):
  1) ثبّت Python 3.11+ مع خيار Add to PATH
  2) فك الحزمة في مجلد وانقر start_bot.bat مرتين
     (كل شيء تلقائي — سيسألك مرة واحدة فقط عن التوكن)
  التفاصيل في DEPLOY.md قسم 14

التشغيل السريع (لينكس/ماك/سيرفر):
  1) python3 -m pip install -r requirements.txt
  2) انسخ .env.example باسم .env واملأه:
       TELEGRAM_BOT_TOKEN  توكن البوت من @BotFather
       ADMIN_USER_ID       رقمك في تلجرام
       API_KEY / PAYMENT_WEBHOOK_SECRET  مفاتيح قوية (الأوامر داخل القالب)
  3) python3 bot.py
